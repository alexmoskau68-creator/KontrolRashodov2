# Контроль расходов

Новый самостоятельный Android-проект для контроля личных расходов.

## План
- главный экран в стиле удобного менеджера расходов
- меню справа
- отдельный полноэкранный экран чека
- камера и галерея
- OCR русского текста
- фактически уплаченная сумма товара
- выбор валюты для каждой покупки
- категории, проекты и отчёты
- без раздела «Настройки»

Проект создаётся с нуля и не изменяет старые проекты `Chekskan` и `KontrolRashodov`.
